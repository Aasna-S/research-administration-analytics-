# Data

This folder contains synthetic research-administration data created for a portfolio demonstration. It does not contain confidential or institutional data.

## Files

| File | Purpose |
|---|---|
| `legacy_proposals.csv` | Raw proposal and award records from the simulated legacy eRA system |
| `current_proposals.csv` | Simulated current-system records containing controlled migration defects |
| `fact_research_activity.csv` | Standardized reporting dataset used for executive Tableau reporting |
| `qa_issue_log.csv` | Record-level migration exceptions requiring investigation |
| `tableau_migration_kpis.csv` | Summary metrics used for Tableau migration-quality KPI cards |
| `field_mapping.csv` | Legacy-to-current field mappings and validation rules |
| `status_mapping.csv` | Crosswalk used to standardize legacy and current workflow statuses |
| `kpi_dictionary.csv` | Governed definitions and calculations for reporting metrics |
| `dim_investigator.csv` | Synthetic investigator reference data |
| `dim_sponsor.csv` | Synthetic sponsor reference data |
| `dim_college.csv` | Synthetic college reference data |

## Disclaimer

All names, identifiers, amounts, organizations, and records are entirely synthetic. This project was created solely to demonstrate data integration, reconciliation, governance, and reporting practices.
